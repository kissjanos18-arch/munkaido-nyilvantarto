Kiss János – Munkaidő-nyilvántartó PWA

GitHub Pages használat:
1. A ZIP tartalmát csomagold ki.
2. A GitHub repositoryban Add file > Upload files.
3. Töltsd fel a fájlokat és Commit changes.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. A megjelenő https://...github.io/... címet nyisd meg iPhone-on Safariban.
6. Safari Megosztás > Főképernyőhöz adás; ha felajánlja, kapcsold be a webappként való megnyitást.

A személyes adatok a készülék böngészőjében tárolódnak. Rendszeresen exportálj JSON biztonsági mentést.
